# ivs C Library
*This library is an infrastructure library by Invisparent.*

## Compatibility
ivs is written in **C11/C17**, with several widely-accepted language extensions. It is expected to be cross-platform and should work on most compilers (e.g. GCC 4.9+ or Clang).

## Project Structure
*   Source files (`.c`) are located in the `./src` folder.
*   Header files (`.h`) are located in the `./include` folder.

## Build
ivs uses **CMake** for building. You can also build it manually if needed.
